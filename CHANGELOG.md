# Changelog

## 0.3.12+87

- Organization backups exported by 0.3.11+86 can be restored. The restore screen rejects the earlier backup identifier before offering a preview. Existing folders and favorites are preserved when a file is rejected.
- The Android application ID is `io.github.tantor_d.phototree`. The earlier 0.3.10+85 development build has a different ID and can remain installed alongside this version. Installations using the 0.3.11+86 maintainer identity can update in place.
- Contributors can build and run a separately signed debug app with the `.contributor` application ID suffix. See the [build instructions](README.md#-platform-and-development).
